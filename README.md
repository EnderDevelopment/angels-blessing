# Angel's Blessing

Angel's Blessing is a Minecraft Paper plugin that provides Innocence Protection for players selected by admins. It integrates with external team or ally plugins, supports PvP protection, and includes Divine Judgment for attackers. The plugin offers configurable status indicators, warnings, and commands for admins to manage blessings.

## Install

1. Download the plugin JAR file from the releases page.
2. Place the JAR file in your server's `plugins` folder.
3. Restart or reload your server.

## Use

1. Admins can select players for Angel's Blessing using the `/bless <player>` command.
2. Blessed players start with active Innocence Protection, which cancels PvP attacks from non-allies.
3. If a blessed player attacks a non-ally, their Innocence Protection is broken.
4. Attackers receive warnings on strikes 1, 2, and 3. On the third strike, the attacker is killed, and a Divine Judgment message is broadcast.
5. Admins can remove blessings using the `/unbless <player>` command.
6. Innocence Protection is restored after death or respawn.
